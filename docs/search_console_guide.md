# Google Search Console Guide

Use this guide to request indexing for the public paper page.

## URL

```text
https://tyilmaz23.github.io/DRLAlgoMapfree/
```

## Sitemap

```text
https://tyilmaz23.github.io/DRLAlgoMapfree/sitemap.xml
```

## Steps

1. Open Google Search Console: https://search.google.com/search-console
2. Add a URL-prefix property:

```text
https://tyilmaz23.github.io/DRLAlgoMapfree/
```

3. Verify ownership using the available Google account method.
4. Open **Sitemaps** and submit:

```text
sitemap.xml
```

5. Open **URL Inspection** and inspect:

```text
https://tyilmaz23.github.io/DRLAlgoMapfree/
```

6. If it is not indexed yet, click **Request indexing**.

Indexing is not instant and ranking is not guaranteed. This only helps Google discover and recrawl the canonical paper page faster.
