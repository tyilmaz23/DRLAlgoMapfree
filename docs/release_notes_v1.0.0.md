# DRLAlgoMapfree v1.0.0

This release archives the reproducibility repository for the IEEE Access article:

**A Comparative Study of DRL Algorithms for Map-Free Robot Navigation With Zero-Shot Sim-to-Real Transfer**

- Article DOI: https://doi.org/10.1109/ACCESS.2026.3684520
- IEEE Xplore: https://ieeexplore.ieee.org/document/11482413/
- Paper page: https://tyilmaz23.github.io/DRLAlgoMapfree/
- Web of Science UID: `WOS:001748497200045`

## Included

- Python-based map-free robot navigation simulator and training pipeline.
- Stable-Baselines3 algorithm support for PPO, SAC, A2C, TD3, and DDPG.
- Optuna hyperparameter search configuration.
- Evaluation scripts for success, collision, timeout, and path-length metrics.
- Reproduction notes and ROS/Gazebo/TurtleBot3 deployment notes.
- Citation metadata through `CITATION.cff`, `.zenodo.json`, `codemeta.json`, `llms.txt`, and Schema.org JSON-LD.
