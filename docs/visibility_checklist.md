# Visibility Checklist

## Profiles

- [ ] Add the publication to ORCID: https://orcid.org/0000-0002-1721-9071
- [ ] Add or claim the paper on Google Scholar.
- [ ] Create a Google Scholar citation alert for this paper.
- [ ] Claim or correct the paper on Semantic Scholar when it appears.
- [ ] Check OpenAlex metadata and request corrections if author/profile matching is wrong.
- [ ] Add the article and repository link to institutional profile pages.
- [ ] Add the article to ResearchGate only if publisher and license terms are respected.

## GitHub Repository

- [ ] Keep the exact article title in the repository README.
- [ ] Keep the DOI as a clickable `https://doi.org/...` URL.
- [ ] Keep `CITATION.cff` at the repository root.
- [ ] Add links to datasets, trained models, simulation videos, and supplementary material if available.
- [ ] Add screenshots or short GIFs of training/evaluation if available.
- [ ] Create a release and archive it with Zenodo if a software DOI is desired.

## Search and AI Discovery

- [ ] Use consistent keywords: deep reinforcement learning, map-free navigation, mobile robot navigation, zero-shot sim-to-real transfer.
- [ ] Include author ORCID links.
- [ ] Include IEEE Xplore, DOI, and Web of Science UID.
- [ ] Keep one public page that can be crawled without login.
- [ ] Add `metadata/schema_org_article.jsonld` to any GitHub Pages or personal web page version.

## Alerts and Monitoring

- [ ] Run the local `citation_monitor.py` once per day with Windows Task Scheduler.
- [ ] Configure email or Telegram notification if desired.
- [ ] Set Google Scholar alerts manually.
- [ ] Re-check Semantic Scholar after a few days if API rate limits occur.
