A Comparative Study of DRL Algorithms for Map-Free Robot Navigation With Zero-Shot Sim-to-Real Transfer

Taner Yilmaz and Omur Aydogmus

IEEE Access, vol. 14, pp. 60268-60284, 2026

DOI Software DOI IEEE Xplore Code ORCID

Summary

This paper compares deep reinforcement learning algorithms for map-free mobile robot navigation and evaluates their zero-shot transfer from simulation to real-world robot navigation. The repository provides the supporting training and evaluation pipeline for PPO, SAC, A2C, TD3, and DDPG experiments.

The work is relevant for researchers studying autonomous navigation, robot learning, reinforcement learning benchmarks, LiDAR-based navigation, and sim-to-real transfer.

Research Signals

Task Map-free mobile robot navigation with randomized static obstacles and no global map input.
Algorithms PPO, SAC, A2C, TD3, and DDPG implemented with Stable-Baselines3.
Transfer Setting Policies are trained in simulation and considered for zero-shot deployment in real-world navigation.
